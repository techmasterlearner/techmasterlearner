# Tech Master Learner Private Limited Website

Files:
- index.html — complete one-page website with Home, About, Team, Services and Contact sections.
- style.css — responsive visual design.
- script.js — mobile menu, scroll reveal, back-to-top button and demo contact-form interaction.

## Run
Open `index.html` in a browser.

## Before publishing
Replace the placeholder team details, Nepal address, phone number and email with the company's actual information. Add the company's official logo if available. Connect the contact form to an email service or backend.
